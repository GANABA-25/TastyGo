# TastyGo 🍔🚚

TastyGo is a modern food delivery mobile application built with **React Native and Expo**. The app provides a seamless food ordering experience, allowing users to discover restaurants, browse menus, place orders, track deliveries, and manage their profiles.

The backend is powered by **Node.js**, **Prisma ORM**, and **PostgreSQL**, providing a scalable and secure REST API for handling users, restaurants, orders, payments, and delivery operations.

TastyGo uses **NativeWind** for styling, bringing the power of Tailwind CSS to React Native for a consistent and responsive mobile UI experience.

---

## Features 🌟

### 👤 User Features

- Secure user authentication and authorization
- User profile management
- Browse restaurants and food categories
- Search for meals and restaurants
- Add items to cart
- Place and manage orders
- View order history
- Track active orders
- Receive order status updates

### 🍔 Restaurant Features

- Restaurant profiles

- Add, update, and remove food items

### 🚚 Delivery Features

- Delivery partner management
- Order assignment
- Real-time delivery status updates
- Location-based delivery tracking

### 📍 Location & Tracking

- Live order tracking
- Delivery location updates
- Map integration
- Real-time courier tracking

### 💳 Payments

- Secure payment processing
- Order payment management
- Transaction history

### 🔔 Notifications

- Order confirmation notifications
- Delivery status updates
- Promotional notifications

# Technologies Used 🛠️

## Mobile Application (Frontend)

### React Native

Cross-platform framework for building native mobile applications for iOS and Android.

### Expo

Used for:

- Development workflow
- Device testing
- Native APIs
- Location services
- Notifications
- App deployment

### Expo Router

File-based routing system for navigation and screen management.

Tailwind CSS styling solution for React Native.

### TypeScript

Provides type safety and better developer experience.

### React Native Libraries

- React Native Safe Area Context
- Expo Location
- Expo Notifications
- Expo Vector Icons

# Backend

## Node.js

JavaScript runtime used for building the backend API.
